## Project Overview

The Secure Cloud-Based Customer Analytics System is a full-stack web application that aggregates, secures, and visualizes customer sales data for business intelligence purposes. The system ingests data from simulated CRM and e-commerce sources, encrypts all personally identifiable information using AES-256, enforces role-based access control across three user roles, and presents live KPI analytics through an interactive React dashboard.

## Database Schema

| Table | Purpose |
|---|---|
| `roles` | RBAC role definitions (SystemAdmin, DataAnalyst, ComplianceOfficer) |
| `users` | System accounts with hashed passwords and role assignment |
| `customers` | Customer profiles — PII fields encrypted with AES-256 |
| `transactions` | Sales and purchase records |
| `segments` | Customer segment assignments (High-Value, At-Risk, Returning, New) |
| `kpi_snapshots` | Daily aggregated KPI metrics generated by ETL |
| `audit_logs` | Full activity log of all authenticated API actions |

## Local Setup

### Prerequisites
- Python 3.11+
- Node.js 18+
- PostgreSQL 16

### Backend

```bash
cd backend
pip install -r requirements.txt
```

Create a `.env` file in the `backend/` folder (see `backend/.env.example`):
```
DATABASE_URL=postgresql://YOUR_USERNAME@localhost:5432/analytics_db
SECRET_KEY=local-demo-secret-key
ACCESS_TOKEN_EXPIRE_MINUTES=60
ENCRYPTION_KEY=local-demo-32-byte-encryption-key!
CORS_ORIGINS=http://localhost:5173,http://localhost:3000
```
`CORS_ORIGINS` is a comma-separated list of allowed front-end origins. When deploying,
add the deployed frontend URL (e.g. `https://your-app.vercel.app`) to this list.

Set up the database:
```bash
createdb analytics_db
psql analytics_db < ../database/schema.sql
psql analytics_db < ../database/seeds/mock_data.sql
```

Start the API:
```bash
uvicorn main:app --reload --port 8000
```

API docs available at: http://localhost:8000/api/docs

### ETL Pipeline

Open a new terminal tab:
```bash
cd backend
python -m app.services.etl_ingestion
```

### Frontend

```bash
cd frontend
npm install
echo "VITE_API_URL=http://localhost:8000/api" > .env.local
npm run dev
```

Open: http://localhost:5173

Requires Node.js 18+ (Vite 5 will fail to build on Node 16 or older).

## Deployment

The app is deployment-ready: the frontend reads its API URL from `VITE_API_URL`
(no hardcoded `localhost`), and the backend reads allowed CORS origins from
`CORS_ORIGINS`. A free-tier path that works well for this stack:

1. **Database + API (Render.com, free tier)** — create a free PostgreSQL instance,
   then a free Web Service pointing at `backend/` with build command
   `pip install -r requirements.txt` and start command
   `uvicorn main:app --host 0.0.0.0 --port $PORT`. Set `DATABASE_URL`, `SECRET_KEY`,
   `ENCRYPTION_KEY`, and `CORS_ORIGINS` (your Vercel URL) as environment variables.
   Load `database/schema.sql` and `database/seeds/mock_data.sql` into the new DB.
2. **Frontend (Vercel or Netlify, free tier)** — import the `frontend/` folder,
   set `VITE_API_URL` to your Render API URL + `/api`, and deploy.

This requires signing up for those services with your own account, so it isn't
something that can be done on your behalf — see `BUGFIX_LOG.md` for details.

## Security Features

- **JWT Authentication** — all endpoints require a valid bearer token
- **Role-Based Access Control** — enforced at the API dependency level
- **AES-256 Encryption** — PII fields (email, phone, address) encrypted before database storage
- **Audit Logging** — every authenticated action logged with user ID, endpoint, IP, and timestamp
- **Password Hashing** — bcrypt used for all stored passwords
